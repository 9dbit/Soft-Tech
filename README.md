# SOFT TECH • BEYOND PLAY
Corporate game provider showcase for the 9dbit studio portfolio, running Next.js 15 and TypeScript.

## Locally
```bash
npm install
npm run dev
npm run build
```

## Railway
Connect GitHub repository `9dbit/Soft-Tech`, branch `main`, Node 20+, standard Next.js build/start commands. Configure `/api/health` as optional service healthcheck. No database is required for the public showcase.

## Art
Logo and game previews are from studio-owned public GitHub repos at `raw.githubusercontent.com/9dbit`. Keep these asset locations public or migrate them to this repo before changing access. No third-party game art is used.

## Contact
The site provides a partnership enquiry email template via mailto; no unconfigured server is claimed to deliver emails. A backend contact delivery integration can be added once an official studio mailbox is confirmed.

## Scope
Brand / game discovery / virtual-credit demo launch only. No deposits, withdrawals or money betting.
